# Local Minimum Array Check

**Difficulty:** `Easy` | **Platform:** [LernyX](https://lernyx.ai)

## Problem Description
Given an array of integers <code>nums</code> of length <code>N</code>. Determine if every element located at index <code>i</code> (where <code>0 < i < N-1</code>) is strictly less than or equal to both its immediate left neighbor (<code>nums[i-1]</code>) and its immediate right neighbor (<code>nums[i+1]</code>). The first and last elements do not need to satisfy this condition.

## Sample Test Cases

**Example 1:**
```
Input: [10, 5, 2, 5, 100]
Output: true
```

**Example 2:**
```
Input: [3, 1, 4, 1, 5]
Output: false
```

**Example 3:**
```
Input: [1, 1, 1, 1, 1, 0, 1]
Output: true
```
